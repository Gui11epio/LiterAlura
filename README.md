# LITERALURA - CHALLENGE ONE - JAVA

## Sobre
É uma aplicação que consome dados de API externa, o Gutendex, o objetivo desse projeto sendo criar um catálogo de livros por meio da API e salvar no banco de dados e permitir uma consulta personalizada

## As consultas
1 - Buscar livro pelo título(Ao buscar ele salva no banco permitindo fazer uma listagem deles nas opções abaixo)

2 - Listar Livros registrados

3 - Listar autores registrados

4 - Listar autores vivos em um determinado ano

5 - Listar Livros em determinado idioma

0 - Sair
